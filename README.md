# Majestic RP Portland Legal Assistant

Информационная система и ИИ-помощник по законодательной базе сервера Portland (Majestic RP).
Приложение выполнено в стиле Apple (Liquid Glass) и работает как внутриигровой оверлей.

## Возможности
- **Автоматическая подгрузка законов**: Скрейпер собирает актуальные данные с форума.
- **Юридический ИИ**: Ответы на вопросы адвокатов и граждан, предложение стратегий защиты (например, по 17.1 УК).
- **Apple Aesthetic**: Дизайн в стиле "жидкое стекло", системные шрифты Apple, плавные анимации.
- **Оверлей**: Скрытие/показ по горячей клавише (настраивается в приложении, по умолчанию `F9`).
- **Темы**: Поддержка светлой и темной тем.

## Инструкция по запуску

### 1. Предварительные требования
Убедитесь, что у вас установлены:
- Python 3.8+
- Node.js 16+
- npm

### 2. Установка зависимостей (Python)
В корневой директории выполните:
```bash
pip install -r requirements.txt
playwright install chromium
```

### 3. Подготовка данных (Скрейпинг)
Чтобы загрузить свежие законы с форума Portland:
```bash
python scraper.py
```
Это создаст файл `laws.json` с актуальной базой.

### 4. Запуск Backend (API)
```bash
python backend.py
```
Сервер запустится на `http://localhost:5000`.

### 5. Запуск Frontend (UI)
Перейдите в папку frontend и запустите React-приложение:
```bash
cd frontend
npm install
npm start
```
Приложение откроется в браузере. По умолчанию оно развернуто на весь экран.
Нажмите `F9` (или настроенную вами клавишу), чтобы скрыть/показать оверлей.

## Настройка
- Нажмите на иконку **Settings** (шестеренка) в приложении, чтобы изменить горячую клавишу.
- Нажмите на иконку **Солнца/Луны**, чтобы сменить тему.
- Используйте вкладку **Legal AI** для консультаций по статьям.
