# Majestic Laws Portland - Overlay App

Программа для подгрузки законодательства сервера Portland (Majestic RP) с встроенным ИИ-помощником.

## Особенности
- **Авто-парсинг:** Загружает актуальные законы прямо с форума Majestic RP.
- **Дизайн Apple:** Эффект Liquid Glass, шрифт SF Pro, анимации Fade In/Out.
- **ИИ-Юрист:** Отвечает на вопросы по законодательству, предлагает варианты защиты (например, для 17.1 УК).
- **Оверлей:** Работает как внутриигровое окно (переключение на F9 по умолчанию).
- **Темная тема:** Настоящий черный цвет (#000000) для OLED и глубокого погружения.
- **Без эмодзи:** Строгий и чистый юридический стиль.

## Установка

### 1. Требования
- Node.js (для фронтенда)
- Python 3.8+ (для бэкенда и скрапера)

### 2. Установка зависимостей
```bash
# Установка зависимостей Python
pip install flask flask-cors rank_bm25 pymorphy3 playwright
playwright install chromium

# Установка зависимостей React
cd frontend
npm install
```

### 3. Запуск
Сначала запустите бэкенд (он автоматически подгрузит законы):
```bash
python3 backend.py
```

Затем запустите фронтенд:
```bash
cd frontend
npm start
```

## Использование
- **F9:** Показать/скрыть оверлей (можно изменить в настройках).
- **Поиск:** Работает как по списку законов, так и внутри конкретного кодекса.
- **Категории:** Быстрое переключение между УК, ПК, ДК и т.д.
- **ИИ:** Перейдите во вкладку "Юрист ИИ" и задайте вопрос, например: "Как дефать 17.1 УК?".

## Структура проекта
- `scraper.py` — Скрапер форума Majestic.
- `backend.py` — Flask API с логикой поиска и ИИ.
- `laws.json` — База данных законов (генерируется скрапером).
- `frontend/` — Исходный код интерфейса на React + Tailwind + Framer Motion.
